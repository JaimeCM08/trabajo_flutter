# 🍃 Mental Health App - Flutter

Aplicación de asistencia para la salud mental y ataques de pánico.

## 📋 Descripción

Una aplicación móvil Flutter diseñada para ayudar a personas que experimentan ataques de pánico o ansiedad. Proporciona ejercicios de respiración, técnicas de relajación, y acceso rápido a contactos de emergencia.

## ✨ Características

- 🔐 **Autenticación**: Login y registro de usuarios
- 🏠 **Dashboard**: Evaluación rápida del estado emocional
- 🧘 **Ejercicios Pre-ataque**: Técnicas preventivas de relajación
- 🆘 **Ejercicios Durante Ataque**: Técnicas de emergencia
- ⭐ **Favoritos**: Guarda tus ejercicios más útiles
- 📞 **Contactos de Emergencia**: Acceso rápido a personas de confianza
- ⚙️ **Ajustes**: Personalización completa de la app
- 🌙 **Modo Nocturno**: Tema oscuro para reducir fatiga visual

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
flutter pub get

# Ejecutar la aplicación
flutter run
```

## 📱 Pantallas

1. **Login/Registro**: Autenticación de usuarios
2. **Home**: Dashboard con "¿Qué tal estás hoy?"
3. **Ejercicios**: Listas de técnicas preventivas y de emergencia
4. **Detalle de Ejercicio**: Pasos guiados para cada técnica
5. **Favoritos**: Ejercicios guardados
6. **Contactos**: Gestión de contactos de emergencia
7. **Ajustes**: Configuración de la aplicación
